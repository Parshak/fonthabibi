# FontHabibi

**Pick a voice, pick a ground.** Free font and color systems for websites, apps, tools, articles, and docs.

🔗 **Live site:** https://YOUR-URL.pages.dev

Every AI-generated build comes out wearing the same cream page and the same serif. FontHabibi fixes that: pick a type set (a "voice") and a color system (a "ground") independently, preview the combination inside the medium it will actually live in (a phone frame, a dashboard, an article), then copy the whole thing as ready CSS tokens or JSON you can paste straight into Claude, Cursor, or v0.

## Features

- **74 voices** — curated display + body + UI font sets, all Google Fonts
- **68 grounds** — complete color systems: background, surface, ink, muted, accent, border, radius
- **5 media previews** — website hero, app phone frame, software dashboard, editorial article, docs page
- **5,000+ combinations**, every one previewed live before you commit
- **Export anything** — copy CSS tokens, download a .css file, grab a working starter page, or save multiple combos and export them all at once
- Free forever, no account, no tracking

## How to use a kit with an AI builder

1. Open the mixer, pick your medium, mix a voice and a ground
2. Hit **Copy CSS** (or copy the JSON)
3. Paste it into your prompt: *"Use these design tokens for everything you build"*

Your build inherits the whole system instead of inventing a generic one.

## Tech

Plain HTML, CSS, and vanilla JavaScript. No framework, no build step, no dependencies. Hosted on Cloudflare Pages. The entire app is two files, view source and poke around.
